เหตุผล: เครือข่ายแบบกระจายศูนย์ (Decentralized) ไม่มีจุดศูนย์กลางเพียงจุดเดียวที่คอยควบคุมทั้งหมด ทำให้เมื่อโหนดใดโหนดหนึ่งล่ม ส่วนที่เหลือยังทำงานต่อได้และเพิ่มขยายโหนดได้ง่าย
เนื้อหาเสริม: โครงสร้างเครือข่าย 3 รูปแบบ 1. Centralized (รวมศูนย์): ทุกเครื่องต่อเข้าศูนย์กลางเดียว มีจุดอ่อนคือ Single Point of Failure (ศูนย์กลางล่ม = ล่มทั้งระบบ)
2. Decentralized (กระจายศูนย์): มีศูนย์กลางย่อยหลายจุดกระจายกัน ทนทานต่อความเสียหายสูง (เช่น อินเทอร์เน็ต, บล็อกเชน)
3. Distributed (กระจายเต็มรูปแบบ): ทุกโหนดเท่าเทียมกันและเชื่อมต่อถึงกันโดยตรง (Peer-to-Peer)

เหตุผล: Internet Protocol Suite (TCP/IP Model) ประกอบด้วย 4 ชั้นหลัก ได้แก่ Application, Transport, Internet และ Network Interface (Link) ไม่มี Database layer
เนื้อหาเสริม: เปรียบเทียบ TCP/IP (4 ชั้น) กับ OSI Model (7 ชั้น) - Application (TCP/IP) = Application + Presentation + Session (OSI)

- Internet (TCP/IP) = Network (OSI)
- Network Access / Link (TCP/IP) = Data Link + Physical (OSI)

เนื้อหาเสริม: 2 โพรโทคอลพระเอกของ Transport Layer - TCP: เน้นความถูกต้อง ครบถ้วน มีการตอบรับ (ACK) หากข้อมูลหายจะส่งใหม่ (เว็บ, อีเมล, โอนไฟล์)
- UDP: เน้นความเร็ว ไม่รอการตอบรับ ยอมให้ข้อมูลตกหล่นได้บ้าง (Live Stream, เกมออนไลน์, วิดีโอคอล)
ข้อ 7 ระบบ LAN น่าจะอยู่ใน layer ใดใน internet protocol suite
  • 1
    Application layer - เพราะระบบ LAN มักใช้โพรโตคอลและบริการระดับสูงเช่น HTTP, FTP, และ DHCP สำหรับการเชื่อมต่อและการแบ่งปันข้อมูลในเครือข่ายภายใน
  • 2
    Network layer - เนื่องจากระบบ LAN มักมีการจัดการเรื่องของเส้นทางการส่งข้อมูลในเครือข่ายภายใน
  • 3
    Transport layer - ในบางกรณีระบบ LAN อาจใช้งานโพรโตคอลระดับนี้เพื่อการส่งข้อมูลที่ซับซ้อนระหว่างเครื่อง
  • ✓
    Data Link layer - เนื่องจาก Data Link layer เกี่ยวข้องกับการสื่อสารระหว่างอุปกรณ์ในเครือข่ายเชื่อมโยงข้อมูลที่อยู่ในระดับฮาร์ดแวร์
เหตุผล: เทคโนโลยี LAN เช่น Ethernet และ Wi-Fi ทำงานในระดับ Link / Data Link Layer โดยอ้างอิง MAC Address ของการ์ดเครือข่ายในการส่งเฟรมข้อมูลหากันภายในวงแลนเดียวกัน
เนื้อหาเสริม: MAC Address vs IP Address - MAC Address (Physical): ติดมากับฮาร์ดแวร์ เปลี่ยนไม่ได้ ใช้สื่อสารในวง LAN เดียวกัน (Layer 2)
- IP Address (Logical): กำหนดโดยเครือข่าย เปลี่ยนไปตามจุดที่เชื่อมต่อ ใช้ส่งข้ามเครือข่าย (Layer 3)

เหตุผล: รูปสี่เหลี่ยมผืนผ้า (Process) ใช้แทนขั้นตอนการปฏิบัติงาน การคำนวณ หรือการประมวลผลทั่วไป เช่น การลิสต์รายการอาหาร
เนื้อหาเสริม: ความหมายของสัญลักษณ์ทั้ง 4 รูปในโจทย์
1. สี่เหลี่ยมผืนผ้า (Process): การปฏิบัติงาน/ประมวลผล
2. ขนมเปียกปูน (Decision): การตัดสินใจ/เงื่อนไข (จริง-เท็จ)
3. วงกลม (Connector): จุดเชื่อมต่อผังงานในหน้าเดียวกัน
4. แคปซูล (Terminator): จุดเริ่มต้น (Start) / สิ้นสุด (End)
